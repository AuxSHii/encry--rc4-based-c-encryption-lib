C Encryption Library

A small project I made while learning C, mainly to understand and implement the RC4 algorithm and 
get more comfortable with low-level concepts in C.

read more about it - https://en.wikipedia.org/wiki/RC4

learned a lot from Jonas Birch — do check his youtube out.. !

I've also included my own visual notes  (./encry_compressed.pdf)
from my learning process. If you're interested, you can use them as a reference 
to understand the concepts and follow along with building the project yourself.


well to end its a learning project — not intended for production cryptography.
